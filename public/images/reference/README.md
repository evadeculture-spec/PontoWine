# Referências de marca (uso interno)

Estas imagens foram fornecidas como **inspiração** e serviram de base à:

- recriação do wordmark "PONTO WINE" (`src/components/brand/logo.tsx`);
- atmosfera de fundo "garrafeira" (`src/components/site/ambient-background.tsx`);
- afinação da paleta (brilho LED magenta/violeta — ver `brand-notes.md`).

| Ficheiro                  | O que mostra                                            |
| ------------------------- | ------------------------------------------------------- |
| `logo-storefront.png`     | Letreiro iluminado da loja com o logótipo "PONTO WINE". |
| `interior-reference.png`  | Interior real: garrafeira, mesas, iluminação magenta.   |

> ⚠️ **Não usar diretamente em produção.** São capturas de ecrã (baixa
> resolução, com interface do browser e fotografias de terceiros
> Google/Tripadvisor). Antes de ir para produção, substituir por:
> 1. um **export vetorial oficial** do logótipo (ver `public/brand/`);
> 2. **fotografias próprias** da Ponto Wine em `public/images/`.
