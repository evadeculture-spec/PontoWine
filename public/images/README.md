# Imagens (`public/images`)

Coloque aqui as fotografias reais da Ponto Wine (espaço, pratos, garrafas,
equipa). Recomendações:

- Formato `.webp` ou `.avif` para performance; em alternativa `.jpg` otimizado.
- Largura máxima ~2000px para imagens de fundo; ~800px para cartões.
- Use o componente `next/image` para lazy-load e otimização automática.

Sugestões de nomes a usar nas secções:

- `hero-bg.webp` — fundo da hero (opcional).
- `experiencia.webp` — secção "A experiência Ponto Wine".
- `vinho-<id>.webp` — foto de cada vinho do catálogo (substituir os placeholders
  visuais na secção de vinhos e nos cartões).
